# PHP & Laravel Learning Journey

A learning portfolio documenting progress from PHP fundamentals to independently building and reconstructing a Laravel appointment-booking application.

## Learning approach
Each lesson explains what a concept is, why it exists, how it works, why its syntax is structured as it is, and how to apply it. Lessons include examples, line-by-line breakdowns, common mistakes, independent practice, and a completion checklist.

## Structure
- `Phase-01-PHP-Fundamentals/` — core PHP syntax and programming concepts.
- `Phase-02-PHP-Functions/` — reusable functions.
- `Phase-03-PHP-OOP/` — object-oriented PHP.
- `Phase-04-Database-Fundamentals/` — database and SQL concepts.
- `Phase-05-Laravel-Fundamentals/` — Laravel structure and core features.
- `Phase-06-Laravel-Eloquent-and-Relationships/` — Eloquent and database relationships.
- `Phase-07-Application-Development/` — practical booking application features.
- `Phase-08-Independent-Project-Reconstruction/` — independent project analysis and recreation.

## Progress
Phase 1 is in progress. Completed lessons currently documented: variables, data types, indexed arrays, adding/removing array elements, associative arrays, modifying associative arrays, and multidimensional arrays. `foreach` loops are currently in progress and will be documented after completion.

## Publishing
A phase is committed and pushed to GitHub after its lessons and documentation are complete and reviewed. Do not mark unfinished phases as completed.
